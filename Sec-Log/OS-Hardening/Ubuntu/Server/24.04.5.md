- Note: If you chose to enable the built-in LUKS encryption, remember to move your recovery-key.txt file to a secure location on a separate device. Keeping the recovery key on the same virtual disk means you won't be able to access it if the system ever fails to boot or you get locked out.

15. Once the VM reboots, you will be prompted to remove the installation media and press `Enter`. Because this is a virtual machine, you can usually just press `Enter` and it will proceed with the boot automatically. Once the system finishes booting, you will be presented with a login prompt.

16. Next, if you skipped network configuration during installation, first ensure you are connected to a network with an active DHCP server. Then check your network interface name by running `ip a` (for example, `ens18` or `eth0`), and open or create the Netplan configuration file with `sudo nano /etc/netplan/00-dhcp-config.yaml`.

- Note: Netplan configuration files inside `/etc/netplan/` can be given any name as long as they end with the `.yaml` extension. Netplan reads and applies all `.yaml` files in numerical and alphabetical order (for example, `00-` is evaluated before `50-`), so later files can override settings from earlier ones.

Add the following configuration, replacing `<interface>` with your actual interface name and keeping the exact two-space indentation:

```yaml
network:
  version: 2
  renderer: networkd
  ethernets:
    <interface>:
      dhcp4: true
```

Press `Ctrl + O` then `Enter` to save, and `Ctrl + X` to exit. Finally, restrict the file permissions to prevent Netplan security warnings by running `sudo chmod 600 /etc/netplan/00-dhcp-config.yaml`, then apply the configuration with `sudo netplan apply`.

---

17. Finally, to wrap up the installation, run `sudo apt update && sudo apt upgrade -y` to update your system now that you are connected to the internet. If a kernel update occurs, reboot the system with `sudo reboot`.

With the system completely installed, updated, and connected to the internet, you can now move on to the next stage: hardening your Ubuntu Server 24.04.5 installation.
